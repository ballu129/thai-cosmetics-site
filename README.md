# SIAM CARE

Первая рабочая версия многостраничного магазина тайской косметики.

## Реализовано

- главная страница;
- каталог;
- отдельный раздел лечебной косметики;
- динамические карточки товаров;
- страницы брендов, доставки, компании и контактов;
- начальная английская версия;
- базовые SEO metadata, robots.txt и sitemap.xml;
- адаптивная верстка;
- структура для дальнейшего импорта 2000+ товаров.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Перед публикацией

Заменить `https://example.com` в `src/app/robots.ts` и `src/app/sitemap.ts` на реальный домен.
